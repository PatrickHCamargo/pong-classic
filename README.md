## ✨ Funcionalidades

- **7 skins visuais** — Classic, Neon, Retro, Cyber, Fire/Ice, Galaxy, Minimal
- **Modo vs CPU** com 3 dificuldades: Fácil, Médio e Difícil
- **Modo 2 jogadores** local na mesma tela
- **Controles touch** otimizados para mobile
- **Efeitos de partículas** nos rebotes
- **Versão web** jogável direto no browser

## 📱 Como instalar (Android)

1. Baixe o APK na [página de releases](https://github.com/Katsuhiro22/pong-classic/releases/latest)
2. No Android: **Configurações → Segurança → Instalar apps desconhecidos** → habilite para o seu gerenciador de arquivos
3. Abra o APK e instale

## 🚀 Build automático

Cada push na branch `main` compila o APK release assinado automaticamente via GitHub Actions.
Cada tag `v*` cria uma [GitHub Release](https://github.com/Katsuhiro22/pong-classic/releases) com o APK anexado.
